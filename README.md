## 📌 Project Overview
This project provides an end-to-end exploratory data analysis (EDA) and business intelligence extraction from a comprehensive E-commerce dataset. It is designed to act as a bridge between raw data and actionable executive strategy, focusing on customer segmentation, purchase behaviour, and revenue optimization.

## 📊 Dataset
* **Source:** Kaggle (Customer Shopping Trends Dataset)
* **Size:** ~3,900 rows, 18+ features
* **Domain:** E-commerce Retail (B2C)

## 🎯 Business Problem
The company faces high customer acquisition costs and flat revenue growth due to blanket marketing strategies and inefficient inventory allocation.

## 🛠️ Tools & Libraries Used
* **Python 3:** Core logic
* **Pandas & NumPy:** Data wrangling, aggregation, and statistical analysis
* **Matplotlib & Seaborn:** Static visualization and distribution analysis
* **Plotly:** Interactive multidimensional mapping

## 📁 Project Structure
- `data/`: Contains the raw CSV data.
- `notebooks/`: Contains the Jupyter Notebook (`ecommerce_analysis.ipynb`).
- `README.md`: Project documentation.

## 💡 Key Insights
1. **Promo Paradox:** Discounts are lowering Average Order Value without driving bulk volume.
2. **Mid-Week Peaks:** Order volume peaks on Tuesdays/Wednesdays, defying the "weekend shopper" myth.
3. **Inventory Imbalance:** Extreme sizes (XS, XXL) represent dead capital; the core market sits strictly in M and L.

## 🚀 How to Run
1. Clone the repository: `git clone https://github.com/ascodess/ecommerce-analysis.git`
2. Install dependencies: `pip install pandas numpy matplotlib seaborn plotly`
3. Launch Jupyter: `jupyter notebook`
4. Open the notebook in the `notebooks/` directory and run all cells.
